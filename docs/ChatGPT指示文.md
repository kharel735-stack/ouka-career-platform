# 桜花HP｜ChatGPTへの指示文（コピペ用）

下の「===ここから===」〜「===ここまで===」を丸ごと ChatGPT に貼り付けて使う。
ChatGPTはこのリポジトリを見られないので、必要な前提はすべて指示文に含めてある。
出てきた結果は、そのまま Claude（私）に渡せば各データファイルに反映する。

---

## 用途A：ネパール語ローカライズ＋短い宣伝文（最優先・一番効く）

===ここから===
あなたはネパール語ネイティブのUXライター兼ローカライズ担当です。
ネパール・ガイダコットにある「桜花スキルトレーニングセンター（OUKA Skill Training Center）」の
公式ホームページで使う文言を、日本語→ネパール語（デーヴァナーガリー）に翻訳します。

【学校の立ち位置（絶対にブレさせない）】
・日本語を教える学校ではなく「日本の建設現場で10年以上活躍できる人材を育てる教育機関」。
・強み4つ：①人材育成（語学校でない）②建設適性を点数で評価③実践100%（現場訓練）④卒業後10年伴走。
・対象：日本の建設で働きたいネパールの若者（N4〜N5レベル）。

【禁止事項（コンプライアンス・厳守）】
・「必ず日本へ行ける／必ず就職できる／ビザが必ず取れる／合格保証／永住保証」など保証表現は一切禁止。
　→「目指す」「条件を満たせば支援・相談」という表現にする。
・実在しない実績・数字・人物を作らない。

【翻訳ルール】
・固有名詞「OUKA Skill Training Center / 桜花」は訳さずそのまま（ネパール語表記は ओउका）。
・自然で、若者にも保護者にも信頼される丁寧な口調。直訳しない。
・日本語1項目につき ne（ネパール語）を1つ返す。

【出力フォーマット】必ずこの表形式だけで返す（前置き・説明は不要）：
| key | ja（原文） | ne（ネパール語） |

【翻訳する原文リスト】※この後に私が日本語の一覧を貼ります。まず「準備OK、原文を貼ってください」とだけ返答してください。
===ここまで===

> ↑貼ったあと、翻訳したい日本語一覧をこちらから渡します（Claudeが `translations.js` から抽出して用意します）。

## 用途B：ロゴ／トップ背景／SNS共有画像の生成プロンプト（画像はChatGPTが得意）

===ここから===
あなたはブランドデザイナーです。ネパールの建設人材育成校「桜花スキルトレーニングセンター
（OUKA Skill Training Center）」用に、次の3点の画像を生成してください。トーンは
「和 × ワークウェア（作業着）」「黒基調・太字・力強い」「桜のモチーフを1つだけ効かせる」。
派手すぎず、建設現場の真面目さと信頼が伝わること。文字を入れる場合は英語表記
「OUKA Skill Training Center」のみ（誤字厳禁、日本語の飾り文字は入れない）。

1. ロゴ（正方形・背景透過・黒＋桜のワンポイント。ヘッダーとファビコン兼用）
2. トップのヒーロー背景（横長16:9。建設現場＋朝礼＋規律を感じる抽象的で上品な構図。人物の顔は特定できない形で）
3. SNS共有画像 OGP（1200×630。校名と「日本の建設現場で活躍する人材を育てる」の趣旨が一目で伝わる）

各画像について、生成前に「構図・色・要素」の案を短く説明してから生成してください。
===ここまで===

> 出力された画像を `assets/images/` に `logo.png` / `hero.jpg` / `ogp.png` として保存すれば反映されます。

## 使い方まとめ
1. まず「用途A」で貼る → 準備OKが返る → Claudeが翻訳対象の日本語一覧を用意 → ChatGPTに渡す → 表が返る → Claudeに渡す → `translations.js` に反映。
2. 「用途B」で画像を作る → ファイル名を合わせて `assets/images/` に置く → Claudeに「置いた」と伝える。
