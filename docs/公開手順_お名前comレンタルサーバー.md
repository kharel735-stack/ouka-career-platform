# 桜花HP 公開手順 ― お名前.com レンタルサーバー

このHPは **ビルド不要の静的サイト（HTML/CSS/JS）** です。
やることは大きく2つだけ：**①ドメインを用意する ②レンタルサーバーにファイルを上げる**。
サーバーの契約・支払い・ドメイン取得は**アニスさんのアカウントと決済**が必要です（私が代わりに決済はできません）。
各画面で何を押すかは下に全部書きます。**詰まったらその画面のスクショを送ってください。**

---

## 0. 全体像（3分で理解）

```
[ドメイン] ouka-skill.com など ─┐
                                 ├─→ ブラウザで https://ドメイン/ にアクセス
[レンタルサーバー] に HP を配置 ─┘   → 桜花HPが表示される
```

- **ドメイン** … 住所（例 `ouka-skill.com`）。お名前.comで新規取得できる。
- **レンタルサーバー** … HPの置き場所。お名前.comの「レンタルサーバー RSプラン」。
- **紐付け** … ドメインをサーバーに向ける設定（下のステップ4）。
- **SSL(https)** … 無料で付けられる（ステップ5）。学校サイトは必須。

> 💡 参考：この静的サイトなら「サーバー契約せず、ドメインだけお名前.comで取り、置き場所は無料のCloudflare Pages」でも公開でき、**ホスティング費0円**にできます。今回はご希望どおり**お名前.comのレンタルサーバー**で進めますが、費用を抑えたい場合は言ってください。

## 3. ステップ手順

### ステップ1｜お名前.comにログイン
1. https://www.onamae.com/ を開く。
2. 右上「**お名前.com Navi ログイン**」。無ければ「**会員登録**」でメール・パスワード登録。

### ステップ2｜ドメインを取得（既に持っていれば飛ばす）
1. トップの検索窓に希望名（例 `ouka-skill`）を入れて検索。
2. `.com` に **申込可能（チェック可）** なものを選ぶ → 「**お申込みへ進む**」。
3. 「Whois情報公開代行」は**無料でONのまま**（個人情報を隠せる）。余計な有料オプション（メール転送・SSL別売等）は**この場では外してOK**（サーバー側で無料SSLを使う）。
4. 支払い → 取得完了。

### ステップ3｜レンタルサーバー(RS)を申し込む
1. お名前.com Navi または https://www.onamae.com/server/rentalserver/ から「**レンタルサーバー RSプラン**」を申込。
2. 契約期間は **12ヶ月一括が割安**（まず12ヶ月でOK）。
3. 支払い → 契約完了。**サーバーの初期設定完了メール**（コントロールパネルURL・ログイン情報）が届く。

### ステップ4｜ドメインをサーバーに紐付け
> ここが一番つまずく所。うまくいかなければスクショを送ってください。
1. **レンタルサーバーのコントロールパネル**にログイン。
2. 「**ドメイン設定 / ドメイン追加**」で、取得した `ouka-skill.com` を**追加**。
3. お名前.com側の**ネームサーバー**を、サーバー用ネームサーバー（例 `01.dnsv.jp`〜`04.dnsv.jp` など、契約完了メール／管理画面に記載のもの）に設定。
   - 同じお名前.com内なので、画面の案内に沿えば自動連携できる場合が多い。
4. 反映まで **数十分〜最大72時間**（多くは1時間以内）。すぐ見えなくても慌てない。

### ステップ5｜無料SSL(https)を有効化
1. コントロールパネルの「**SSL / 無料SSL設定**」で `ouka-skill.com` を選び**有効化**。
2. ドメインのDNSが反映済みでないと発行に失敗するので、ステップ4の反映後に行う。
3. 反映後、`https://ouka-skill.com/` でカギ🔒が付けばOK。
4. 「http→httpsへ自動リダイレクト」の設定があればONに。

### ステップ6｜FTP接続情報を確認
コントロールパネルの「**FTPアカウント / FTP情報**」で以下を控える：
- FTPサーバー名（ホスト）
- FTPユーザー名
- FTPパスワード
- **アップロード先フォルダ（ドキュメントルート）** ＝ 追加したドメインのフォルダ（例 `/ouka-skill.com/` や `public_html` 配下）。**ここのトップに `index.html` が来るように置く。**

### ステップ7｜ファイルをアップロード（2通り、好きな方）

**方法A：ブラウザのファイルマネージャー（簡単）**
1. コントロールパネルの「**ファイルマネージャー**」を開く。
2. ステップ6のドキュメントルートに入る。
3. `公開用_アップロード.zip`（このリポジトリ内 `ouka-career-platform/公開用_アップロード.zip`）を**アップロード → 解凍**。
4. 解凍後、そのフォルダ直下に `index.html` と `assets/` が並んでいればOK。

**方法B：FileZilla（無料FTPソフト・ドラッグ＆ドロップ）**
1. FileZilla を入れる（https://filezilla-project.org/）。
2. ステップ6のホスト／ユーザー／パスワードで接続（暗号化=SFTP/明示的FTP over TLSを選ぶ）。
3. 右側（サーバー）でドキュメントルートを開く。
4. 左側（自分のPC）で `ouka-career-platform` の中の
   **`*.html` すべて＋`assets` フォルダ**を、右側へドラッグしてアップロード。
   ※ `apps-script/`・`docs/`・`README.md`・`.gitignore` は**上げない**（Web公開に不要）。

### ステップ8｜公開確認
1. `https://ouka-skill.com/` を開く → トップが表示。
2. メニュー各ページ・「無料適性診断」→結果まで動くか。
3. スマホ（実機）でも開く（学生はスマホが主）。
4. タブに🌸(桜)アイコン(favicon)が出るか。

## 4. 公開後にやること（HPは今すぐ公開できる。以下は後追いでOK）

**フォーム未設定でも公開して大丈夫**：送信ボタンは自動で「準備中」表示になり、嘘の完了は出ない設計です。下記は揃い次第、該当ファイルだけ差し替えて**再アップロード**すれば反映されます。

| やること | 直すファイル | 私に渡せば私が直します |
|----------|--------------|------------------------|
| 学校メール・Googleマップ | `assets/js/config.js`（`email` / `mapUrl`） | メールと地図URLを教えてください |
| 各Googleフォーム連携 | `assets/js/config.js`（`endpoints.*FormUrl`） | フォームURLを教えてください |
| Apps Script直接送信 | `assets/js/config.js`（`appsScriptUrl`） | /exec のURLを教えてください |
| SNS共有サムネ(OGP) | 全HTMLの`<head>`＋ロゴ/OGP画像 | **ドメインが決まったら私が全ページに一括で入れます** |
| ロゴ・トップ写真 | `assets/images/`（`logo.png` `hero.jpg` `ogp.png`） | 生成手順は `docs/ChatGPT指示文.md` |

## 5. トラブル時（スクショを送ってください）

| 症状 | ありがちな原因・対処 |
|------|----------------------|
| 「見つかりません」 | DNS未反映（待つ）／`index.html`がドキュメントルート直下に無い |
| 文字化け | 文字コードUTF-8で保存されているか（このサイトは全てUTF-8で問題なし） |
| CSSが効かず素のHTML | `assets/`フォルダごと同じ階層に上げていない／パス違い |
| 🔒が付かない・https不可 | SSL未発行（DNS反映後にSSL有効化→数十分待つ） |
| 診断は動くが送信が「準備中」 | 正常。`config.js`のフォームURL未設定のため（上の表参照） |
