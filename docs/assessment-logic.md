# 適性診断のスコア設計

正本コード: [`assets/js/assessment-scoring.js`](../assets/js/assessment-scoring.js)
質問定義: [`assets/js/assessment-questions.js`](../assets/js/assessment-questions.js)

## 基本方針
- 職種ごとに 0〜100 点を算出し、**上位3職種**を表示します。
- 分母 `max` は **その職種の全要素の重み合計（固定）**。`raw / max × 100` で **正規化**（100を超えない）。
- **未回答は raw に 0**（その要件の“証拠なし”）。回答が重なった項目だけで満点化するのを防ぎ、
  職種間の判別性を保ちます。**多く答えるほど・要件に合うほどスコアが上がる**（直感的）。
- この診断は **参考情報**。低い点数は「不向き」ではなく「現時点では優先度が低い」と表示します。

## 加点の型
- `L(qid, w)` … likert（1〜5）。`1→0点`, `5→満点(w)`。`raw += (v-1)/4 × w`, `max += w`。
- `M(qid, map, w)` … 選択式。`map = {value: 0〜1の係数}`。`raw += 係数 × w`, `max += w`。
  - よく使う `YSN`＝{YES:1, SOME:0.5, NO:0}、`YN`＝{YES:1, NO:0}。
- 重要な要素ほど重み `w` を大きく（例：その職種の実務経験は 1.5）。

## 職種ごとの評価要素（抜粋）
- **建設**: 体力・屋外・道具・高所・チーム・安全ルール・時間厳守・報告・建設経験・重量物・立ち仕事。
- **介護**: 人の世話・高齢者・傾聴・会話・忍耐・学習意欲・夜勤・衛生・介護経験。
- **農業**: 屋外・早朝・体力・動植物・反復・地方志向・天候・農業経験。
- **外食**: 接客・料理・繁忙時の落ち着き・チーム・清潔・会話・立ち仕事・シフト・飲食経験。
- **宿泊**: 接客・丁寧さ・チーム・落ち着き・会話・立ち仕事・夜勤。
- **製造**: 反復の正確さ・細かさ・道具・安全・チーム・立ち仕事・夜勤・製造経験。
- **自動車整備**: 道具/機械・論理・細かさ・新技術・学習・運転・製造経験。
- **IT・エンジニア**: PC・論理・新技術・読解・学習・細かさ・PC経験・学歴。
- **事務・通訳**: 日本語レベル（重み2）・読解・会話・正確さ・PC・傾聴・学歴。

## 出力（analyze の戻り）
- `scores`: 全（表示対象）職種のスコア（降順）
- `top3`: 上位3（code, name{ja,en}, score）
- `strengths`: 強み最大3（likertが4以上の項目から）
- `cautions`: 確認が必要な点 最大3（日本語・健康・高所・家族同意 など。断定しない）
- `overall`: 総合コメント（トップ職種名を差し込み）

## 調整のしかた
- **職種を増やす**: `JOBS` に1件追加（code＋name＋factors＋メッセージ）。表示名は自動で反映。
- **重みを変える**: 各 factor の `w` を変更。
- **必要日本語/準備/理由の文言**: 各職種の `neededJp` / `prepare` / `why`（{ja,en}）を編集。
- **表示する職種**: `config.js` の `jobStatus` を `hidden` にすると診断・表示から除外。
