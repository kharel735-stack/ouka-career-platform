# images フォルダ

ここに画像（ロゴ・写真・OGP画像など）を入れます。Phase1は画像なしでも動作します。

## 置くとよいもの（任意）
- `logo.png` … ロゴ（ヘッダー用）。現状はテキスト＋「桜」マークで代用。
- `hero.jpg` … トップのヒーロー背景（現状は緑グラデーションで代用）。
- `ogp.png` … SNS共有用（1200×630）。

## 注意
- 実在しない実績・写真を使わない（本物の許諾済み素材のみ）。
- 生徒・スタッフの写真は本人同意を得てから使用。
- 画像は軽量化（Web用に圧縮）してから配置。
- パスは各HTMLから `assets/images/ファイル名` で参照。
