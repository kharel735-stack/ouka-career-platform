# VOICE RULES｜本人性を保つための執筆ルール

本人確認（2026-08-28、第1制作バッチのフィードバック）に基づき登録。今後のすべての制作バッチ（SERIES 03以降を含む）で適用する恒久ルール。MASTER STORYが「事実の基準」であるのに対し、これは「書き方・声のトーンの基準」である。

---

**1. 本人の発言に強い具体表現がある場合、綺麗な広告コピーに置換しない。**
例：「言葉は黙っときゃなんとかなる。でも腹は減る。」のような本人表現を優先する。編集して滑らかにしすぎない。

**2. 本人が言っていない「人生を変えた」「運命」「原点」「夢を諦めなかった」等のドラマチックな表現を追加しない。**

**3. STORYを毎回OUKAへ回収しない。**
経験と現在の教育思想につながりがある場合も、「だからOUKAを作った」と単純化しない。「現在の考え方の土台の一つ」「現在の教育にもつながっている経験の一つ」程度に留める。

**4. WebsiteとOUKA公式は編集された文章でよい。**
ただしThreadsと個人Facebookは、本人が実際に話す言葉・リズムを優先する（ですます調の均質な整文より、短く・直接的な言い方を優先）。

**5. 個人Facebookで、一般的な経営者SNSの書き出し・締め方を使用しすぎない。**
「改めて自己紹介します」「これから少しずつ発信していきます」「よろしくお願いします」などは必要な場合だけ使う。

**6. 実体験が強い場合、LESSONを無理に文章化しない。**
読者がエピソードから理解できる場合は、説明しすぎない。

**7. OUKA接続では、人生の出来事→OUKAの直接因果を創作しない。**
実際の大きな流れは：

```
日本で外国人として生活した経験
→ 日本社会で育つ
→ 社会人になる
→ 建設・現場を経験
→ 外国人と働く
→ 自分自身も外国人を使う側になる
→ 教育不足による課題を実感
→ 日本へ行く前の教育が必要だと考える
→ 現在のOUKA
```

幼少期の給食、友人、剣道、先生などは、この考え方を形成した複数の経験の一部として扱う。単独の経験を直接OUKAの起点として描かない。

**8. 「養鶏設備会社で働いた」など、雇用関係を断定しかねない表現を避ける。**
「養鶏設備会社ハイテムの仕事として、養鶏場設備・機械設置に携わった」を基本事実とする。

**9. 辻先生について、「人生を変えてくれた先生」と勝手に拡張しない。**
本人の現在の表現は「自分にとってすごく大事な先生」「今でも覚えている大切な先生」である。
