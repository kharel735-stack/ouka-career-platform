# NEPAL ATTENTION MODE｜一時運用モード

## 背景

2026年8月26日、ネパールで大規模な洪水災害が発生し、現在ネパールに国際的な関心が集まっている。この状況を利用した露骨な宣伝・災害便乗マーケティングは行わない。一方で、「今ネパールに関心を持っている人たちに、ネパールで実際に活動している人間として、ネパールと日本について正確に伝える」ことは積極的に行う。

目的は短期的な集客ではなく、長期的な認知形成である：

```
カレル・アニス
→ ネパール
→ 日本との関係
→ 日本で働くネパール人
→ 教育の必要性
→ OUKA / ABAS
```

これは**一時的なモード**であり、Founder Content System本体（`DESIGN.md` / `VOICE_RULES.md` / SERIES 01〜10）の恒久ルールを置き換えるものではない。関心の高さが落ち着いた時点で通常のPRIORITY順制作（`DESIGN.md` セクション5）に戻す。

## 発信レイヤー

| LEVEL | 内容 | 営業・学校宣伝 |
|---|---|---|
| 1 | 災害・現地情報 | 入れない |
| 2 | ネパールを知ってもらう（社会・若者・仕事・教育・文化・日本との関係） | 入れない |
| 3 | Founder Story（ネパール生まれ〜日本で育った本人の経験） | 入れない |
| 4 | 日本×ネパール（日本で働くネパール人、企業、就労、教育、文化適応） | ほぼ入れない |
| 5 | OUKA / ABAS | 十分な文脈がある場合のみ、自然に |

**LEVEL 1からLEVEL 5へ毎回誘導しない。** 特に災害投稿へ、OUKAの募集・入学案内・営業CTAを直接接続することは行わない。

## LEVEL 1（災害・現地情報）の厳格ルール

- 営業・学校宣伝を一切入れない。
- 被災者への配慮と正確性を最優先する。
- 死者・行方不明者等の数字は、**投稿直前に公的情報（ネパール政府・国際機関等の一次情報）を確認する**。本ドキュメント内やその他のコンテンツファイルに具体的な死傷者数を事前に書き込んで固定化しない（投稿時点で古い数字になるため）。
- センセーショナルな写真・表現・CTAを使用しない。
- LEVEL 1の本数は少数に留める（今回のカレンダーでは2件のみ）。

## 運用ルール

1. 災害関連（LEVEL 1）は少数に留め、その後は「ネパールを知る」（LEVEL 2）「日本とネパール」（LEVEL 4）「Founder Story」（LEVEL 3）へ移行する。20本すべてを災害コンテンツにしない。
2. LEVEL 1・2の投稿を数本挟んでから、既存のFounder Story（SERIES 01・02a・02b）を投入する。災害発生直後に個人ブランディング色の強いコンテンツを出さない。
3. LEVEL 5（OUKA/ABAS）はカレンダーの終盤、文脈が十分に積み上がった段階でのみ、少数（今回は2件）に留める。
4. 事実確認が必要な項目（統計・数字・団体名など）は、投稿本文の制作前に確認する。未確認のまま公開しない。
5. 本モードの適用期間は目安14日間。以降は `DESIGN.md` の通常のPRIORITY順制作（SERIES 03・05・09など）に戻る。
6. 執筆時は `VOICE_RULES.md` を適用する（本人性優先、綺麗な広告コピー化しない、災害便乗を煽る表現をしない）。
