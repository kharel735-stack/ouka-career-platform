| 優先度 | 意味 |
|---|---|
| TODAY | 本日投稿する |
| NEXT | 直近で投稿する |
| THEN | その次に投稿する |
| LATER | さらに後で投稿する |
| HOLD | 条件が整うまで保留 |
| DROP候補 | 現状では積極的に使用しない（採用するとしても最終盤・要再検討） |
